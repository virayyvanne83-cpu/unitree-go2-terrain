# Go2 本机验收记录

源码发布的安装、预览与回放入口见 [GitHub 使用说明](../README.github.md)，原测试机器说明见 [本机说明](../README.local.md)。

本轮采用用户提供的 48 维原课程配置、课程环境及 MuJoCo 控制器/导出工具，对本机运行链路完成了不训练的复核。

| 检查 | 原测试机器结果 |
| --- | --- |
| 48 维主线 | ActorCritic/PPO，无历史观测、无特权观测、无速度课程；两独立 [512,256,128] ELU MLP |
| 课程规则 | 13 类数值/逻辑检查通过；部分晋级输入为构造指标，不是自然学习结果 |
| trimesh / heightfield | 各 4096 环境、160 策略步，观测 [4096,48]，状态有限 |
| 固定地形推理 | 4096 环境短程固定指令检查通过，无权重更新 |
| MuJoCo 六组地形 | 每组 56 条原生射线，高度最大误差约 2.15e-8 m；各 6 秒有限状态回放 |
| 控制器 | 质心速度、48 维切片、23.7/35.55 N m 饱和、50 Hz 调用、键盘状态和 reset 检查通过 |
| 工程检查 | 36 个活动 Python 文件 AST、git diff --check、pip check 通过，检查点哈希未变 |

原测试机器的详细记录位于 `source_alignment/REPORT.md`，旧版报告备份在 `before_source_alignment/verification/REPORT.md`。这些生成数据和历史备份未纳入 GitHub 源码发布；可以使用本目录的检查脚本重新生成。不要将旧版导出配置作为当前控制器的配置。

本轮没有 PPO 更新，也没有恢复此前被用户叫停的训练。原 model_1500 未提供；当前默认 model_3 仅为历史短程验收策略，不能代表行走质量。此前 model_50 保留为旧复建版本的中途产物。
